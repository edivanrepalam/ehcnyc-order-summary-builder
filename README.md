# EHCNYC Order Summary Builder

Create order confirmation emails with a live preview, conditional order comments, editable unit presets, and reusable resource links.

Live site: https://edivanrepalam.github.io/ehcnyc-order-summary-builder/

## Use

Open the live site or open `index.html` locally. Complete the form, then copy the email for Gmail, copy its HTML, or download it. Form entries stay in the current browser page and are not automatically saved or uploaded.

## Update

`index.html` contains the application, styles, email templates, and configuration. No build step is required.

Update the file, verify the affected behavior in a browser, commit the change, and push to `main`. GitHub Pages publishes from the repository root. `.nojekyll` keeps the site as plain static HTML.

Email templates use presentation tables and inline styles so copied and downloaded emails retain their formatting.
