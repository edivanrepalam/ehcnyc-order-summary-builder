# Project guidance

- The application source is `index.html`; keep changes limited to the requested behavior or appearance.
- Preserve the email templates' presentation tables and inline styles.
- Preserve form behavior across new, duplicated, and reset orders. Validate changes to conditional fields, default links, and email output in a browser.
- GitHub Pages serves `main` from `/`. Deploy requested updates with a normal commit and push, then verify the live page.
- Keep real patient entries, credentials, local browser profiles, and temporary screenshots out of the repository.
